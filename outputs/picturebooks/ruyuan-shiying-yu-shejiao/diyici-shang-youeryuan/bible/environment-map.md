# 《第一次上幼儿园》环境地图

- 时间与天气：晴朗清晨，柔和自然光。
- 核心场景：幼儿园入口、教室门口、储物格、圆地毯活动区、靠窗安静角。
- 起点：家门口和幼儿园外侧步道。
- 目标点：教室圆地毯边缘和靠窗安静角。
- 行动路线：家门口 -> 蓝绿色园门 -> 圆窗教室门 -> 储物格 -> 圆地毯边 -> 门口接回 -> 园门外。
- 路径轴线：入口阶段保持从左向右进入；教室内保持窗户在左、储物格在后、圆地毯在中、安静椅在边缘。
- 固定地标：蓝绿色圆洞园门、圆窗教室门、低矮储物格、圆形蓝地毯、珊瑚色软球篮、左侧窗户、靠窗安静椅。
- 主光源方向：左侧窗光和入口树影。
- 禁改项：不得画成阴暗封闭空间、拥挤走廊、训导场景、公共机构压迫感或班级牌文字场景。

## 镜头轴线

- 第 1-5 页：从家门/园门到教室内，行动方向以左到右为主。
- 第 6-8 页：以圆地毯和左窗为主锚点，低机位服务幼儿视角。
- 第 9-10 页：反向回到妈妈和园门，保留圆窗门或蓝绿门作为空间闭合。
