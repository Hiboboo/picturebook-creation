# 《小肚肚叮一下》环境地图

## 空间总览

- 时间：晴朗白天。
- 主光源：左侧窗户柔和日光，浴室顶部漫反射白光。
- 核心场景：客厅游戏垫和右侧小浴室。
- 起点：客厅左侧圆角游戏垫，小葫芦搭积木。
- 目标点：浴室右侧的小马桶。
- 行动路线：游戏垫左下 -> 客厅中部 -> 右侧浴室门 -> 小马桶前 -> 小马桶上 -> 回到游戏垫边。

## 固定地标

- 客厅：浅木地板、圆角游戏垫、蓝黄浅木色大颗粒积木。
- 浴室门：在画面右侧，作为第 1-5 页主要空间锚点。
- 浴室：白色小瓷砖、薄荷绿毛巾、奶油白小马桶、薄荷绿坐圈、小脚凳。
- 小马桶：浴室门内右下方，正面略朝向客厅。

## 镜头轴线

- 主轴线：客厅左侧到浴室右侧。
- 常规方向：小葫芦从左向右移动。
- 反向收束：第 8 页从浴室看回客厅，但必须保留浴室门框和游戏垫作为锚点。
- 越轴限制：不得让浴室突然出现在左侧，也不得把游戏垫和浴室位置互换。

## 允许变化项

- 小葫芦从坐在游戏垫、站起、走路、看小马桶、坐下、穿好裤裤回到游戏垫。
- 妈妈从游戏垫边蹲下，到跟随一步，再到浴室门旁等待。
- 画面可从远中景切到近景和特写，但固定地标不得漂移。

## 禁改项

- 不得把浴室画成公共厕所、医院场景、阴暗空间或惩罚空间。
- 不得出现脏乱、异味可视化、夸张清洁剂或成人厕所压力。
- 不得出现门被锁住或成人挡住孩子退路。
