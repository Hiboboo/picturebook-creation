# 《被窝里的晚安信》故事与文字 QA

## 核心检查

| 检查项 | 结果 | 依据 |
|---|---|---|
| 单一核心主题 | 通过 | 全书只讲孩子借由可被回应的连接，尝试在自己的床上先躺一会儿。 |
| 年龄适配 | 通过 | 面向 3–4 岁；10 个故事页，每页一至两句、动作具体。 |
| 儿童视角 | 通过 | 洗脸、抱玩偶、上床前想再说晚安、画一张小纸，均为幼儿可感的经验。 |
| 情绪接纳与选择权 | 通过 | 团团抱紧小兔并说出需要；妈妈给出“画信 / 坐一会儿”两个真实选项。 |
| 无催促、比较、羞耻或奖励交易 | 通过 | 未出现“勇敢、乖、别人都会、不能再叫”等话语；无奖品、掌声或贴纸。 |
| 成人支持具体 | 通过 | 妈妈蹲低、等待、提问，并按团团的约定把信放在书边。 |
| 最小可行尝试 | 通过 | 团团只选择“我先躺一会儿”，没有被要求整夜独睡。 |
| 反复结构推进 | 通过 | 小纸 → 晚安信 → 交给妈妈 → 放在书边，孩子的主动决定逐步增加。 |
| 每页单一变化 | 通过 | 依次推进准备、发现、犹豫、表达、选择、作画、递交、履约、躺下。 |
| 朗读与禁用表达 | 通过 | 句子短、停顿自然；未使用贬低、恐吓、条件交换或成人腔表达。 |
