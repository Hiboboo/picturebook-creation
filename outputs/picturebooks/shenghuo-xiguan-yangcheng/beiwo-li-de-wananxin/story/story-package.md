## 2. 基本信息

- 系列：生活习惯养成系列。
- 书名：《被窝里的晚安信》。
- 主题：独立睡觉。
- 图/文：小葫芦。
- 主要适合年龄：3-4 岁。
- 可延伸年龄：2-5 岁亲子共读。
- 核心主题：孩子可以用自己选择的、可被回应的小小连接，慢慢练习在自己的床上躺一会儿。
- 孩子的生活入口：刷牙洗脸后，到了要躺进自己小床的时刻，却还想和照料者说晚安。
- 目标情绪变化：平静准备 → 犹豫黏连 → 说出需要 → 自己选择连接办法 → 看见约定被做到 → 安心地先躺一会儿。
- 故事页数：10 页，不含封面。
- 画面风格：清爽的水粉平涂与细彩铅线条；具有真实生活痕迹的现代家庭夜晚，不使用泛黄滤镜、蜡烛感或复古纸纹。
- 视觉细节密度：适中偏简洁。
- 色彩设计策略：雾蓝与青灰承接安静夜晚，珊瑚红信封作为主动表达的强调色，鼠尾草绿与云白维持安全、清爽的室内感；暖意来自亲子回应而非黄色滤镜。
- 图片比例：固定 `3:4` 竖版。
- 锁定像素尺寸：`1536×2048`。
- 文字安全边距：画布宽高至少 `6%`；正文保持在自然的低细节区域。
- 固定输出目录：`outputs/picturebooks/shenghuo-xiguan-yangcheng/beiwo-li-de-wananxin/`。

## 3. 儿童发展与情绪安全策略

- 孩子可能感受到的情绪：不想马上分开、想再确认、犹豫、专注、安心。
- 故事如何接纳这种情绪：团团直接说出“还想说晚安”，没有被要求立刻坚强、安静或睡着。
- 孩子拥有的选择：先坐一会儿、画一封信、请妈妈把信放到书边、继续抱着小兔、先自己躺一会儿；想再次呼唤照料者也被允许。
- 成人如何提供支持：妈妈蹲到团团视线高度，问“画信，还是坐一会儿？”，并执行孩子提出的放信约定；她在客厅可被听见和回应。
- 故事中的最小可行尝试：团团不被要求整夜独睡，只选择“先自己躺一会儿”。
- 结尾如何避免“必须克服”：团团只选择“先自己躺一会儿”，不宣称她必须睡整夜或永远不再需要陪伴。
- 奖励、掌声或贴纸的处理：全书不出现奖励、掌声、贴纸或交换条件。
- 禁用表达：`别哭`、`你都这么大了`、`别人都会自己睡`、`画了信就不能叫我`、`你乖乖睡妈妈才高兴`、`不许出来`。

## 4. 故事设定卡

- 背景：一个普通夜晚；团团的卧室有一张矮床、窗边小桌、低书架和一块略有折痕的地毯。妈妈在相邻客厅的单人椅上读一本无字封面的深蓝书。
- 儿童视角：来自孩子熟悉的身体经验——洗完脸、抱着玩偶、要上床时还想和大人说一句晚安；画一张小画是可理解、可选择的连接方式。
- 故事弧线：睡前准备 → 发现纸和蜡笔 → 抱紧玩偶的犹豫 → 说出需要 → 成人给选择 → 孩子选画信 → 画出小手 → 主动约定信的位置 → 成人可靠执行 → 孩子先躺一会儿。
- 重复结构：`晚安信`从“一张小纸”变为“孩子画的信”再变为“放在妈妈书边的信”；每次多了一点孩子的主动决定。
- 页间推进：每页仅推进一个动作或情绪；镜头由广到近、由亲子同框到两处空间的可见约定，最后回到团团的安静近景。
- 温暖结尾：团团没有被评价为勇敢或乖；她只是在知道妈妈会回应、自己的小画被珍惜时，选择再躺一会儿。
- 故事禁改项：不出现小夜灯、门缝光、星星数数或可怕影子；不出现锁门、强迫分离、哭闹羞辱、奖励交易或“整夜独睡”要求。

## 5. 四项锁定

1. **故事锁定**：面向 3-4 岁，10 个故事页；核心主题仅为“通过被回应的连接，尝试在自己的床上躺一会儿”。
2. **角色锁定**：C01-团团、A01-妈妈、P01-小兔抱偶；服装、发型、身高和道具状态见 `bible/character-bible.md`。
3. **空间锁定**：卧室床在画面左侧、窗边画桌在右后侧、矮书架在后墙；客厅单人椅靠左、书边小边几靠右。空间地图见 `bible/environment-map.md`。
4. **版式锁定**：全部为 1536×2048、3:4 竖版；无字源图 + 可编辑后期文字层；正文不超过 3 行且避开脸、手、信封和小兔。
