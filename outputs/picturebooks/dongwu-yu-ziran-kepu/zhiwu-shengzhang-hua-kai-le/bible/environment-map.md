# 环境与空间连续性地图

## E01-同一座小花圃

- 地表：低矮草地、松软花圃土、柔和天空。
- 地下：上层较松、下层略深，水分增加时颜色自然变深。
- 种植点：画面中心略偏下，位于 D01 与 D02 之间。
- D01：蓝灰小石头，固定在地表左侧。
- D02：浅棕无字木标记，固定在地表右侧，略向右倾。
- 主光源：右上方。
- 根芽轴线：根向画面下方，芽和茎向画面上方。

## 禁改项

- 不左右镜像 D01/D02。
- 不让根向上或芽向下。
- 不移动种植点。
- 不出现第二块花圃、花盆、温室或室内场景。
- D02 不得出现任何可读文字、数字或符号。
