# 角色与生长形态圣经

## S01-向日葵

- 身份：同一株向日葵，从种子到完全开花。
- 种子：暖棕色、略扁椭圆、尖端朝右上、浅奶油色纵纹。
- 阶段：吸水鼓起 → 种皮裂开 → 白色胚根向下 → 绿色幼芽向上 → 两片子叶展开 → 真叶出现 → 单一主茎长高 → 花苞形成 → 单一花盘开放。
- 真叶：中绿色、宽卵形、边缘轻微锯齿、叶脉可辨。
- 成株：单一主茎、一个主花盘；棕色花心，低饱和黄色花瓣。
- 表情：不画五官；以姿态、叶片角度和光线表达状态。
- 禁改项：物种、单株身份、种子纵纹、根芽方向、单一主茎、单一花盘、生长顺序。
- 可变项：生长阶段、叶片角度、雨水状态、景别和光线。
- 参考图：已生成，路径 `character-reference-sheet.png`。六阶段顺序、单一主茎、单一花盘、种子纵纹和无字要求通过初检。
