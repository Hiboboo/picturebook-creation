## 3. 儿童发展与情绪安全策略

- 孩子可能感受到的情绪：安静、好奇、等待变化、发现、惊喜。
- 故事如何接纳这种情绪：小种子不被催促，只在环境合适时一点点发生变化。
- 孩子拥有的选择：本故事不是行为任务；共读时孩子可以先观察、猜下一页、模仿伸展或暂停。
- 成人如何提供支持：只陪孩子观察“哪里变了”，不把植物生长比作孩子必须快点长大。
- 故事中的最小可行尝试：发现一处小变化，如种皮裂缝、白根或两片子叶。
- 结尾如何避免“必须克服”：花开是自然过程的结果，不代表比赛、胜负或价值评判。
- 奖励、掌声或贴纸的处理：不出现。
- 禁用表达：“快点长大”“别人都开花了”“你要努力”“真乖”“最漂亮的花”。

## 4. 故事设定卡

- 背景：同一座春末清晨的小花圃，地表左侧有蓝灰小石头，右侧有无字木标记。
- 儿童视角：通过雨声、泥土湿度、根芽方向、叶片和花苞等可见变化理解植物生长。
- 故事弧线：沉睡 → 雨水渗入 → 种皮裂开 → 根向下 → 芽向上 → 子叶见光 → 真叶生长 → 花苞形成 → 花开放。
- 重复结构：“滴答，滴答”“照一照”“伸一伸”“顶一顶”“一片，两片”；每次都对应新的真实生长变化。
- 页间推进：每页新增一个阶段、方向或结构，不重复同一动作。
- 温暖结尾：清晨的向日葵完全开放，正文只说“花开了”，不追加说教。
- 故事禁改项：向日葵、生长顺序、单株主角、自然环境作用、无比赛与价值评价。

## 10. 给家长的文字

- 这个故事想让孩子感受到什么：植物不会突然长大；水、阳光和时间会带来一连串小变化。
- 共读提醒：不要用故事催孩子“快点长大”或把开花比作必须取得的成绩。
- 亲子互动：听“滴答”时轻敲桌面；用手指向下模仿根、向上模仿芽；找子叶和真叶的区别；观察家中植物今天和昨天哪里不同。
- 可使用的支持性语言：“你发现哪里变了？”“我们来找找根往哪边长。”“植物会按自己的时间慢慢长。”
- 不建议使用的语言：“你也要快点长大。”“别的小朋友都会了。”“努力才会开花。”
- 适合幼儿年龄：主要 3–4 岁，可延伸至 2–5 岁亲子共读。
