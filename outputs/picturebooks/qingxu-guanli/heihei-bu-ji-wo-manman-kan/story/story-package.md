- 目标情绪变化：从想试一试，到有点怕，再到被听见、能选择、愿意走近一点，并形成自己的小办法。

## 3. 儿童发展与情绪安全策略

- 孩子可能感受到的情绪：好奇、犹豫、有点怕、被听见、安心一点、有把握。
- 故事如何接纳这种情绪：正文直接允许小米说“我有点怕”，没有让成人否定或纠正。
- 孩子拥有的选择：先看、牵手、走一步、照一照、贴一个路径线索、下次仍可慢慢来。
- 成人如何提供支持：妈妈蹲低到小米视线高度，给两个具体选择，伸出一根手指等待小米牵住，陪小米看清影子和声音来源。
- 故事中的最小可行尝试：小米只需要走到杯架拿到小蓝杯，不需要证明自己以后都不怕黑。
- 结尾如何避免“必须克服”：结尾说的是“黑黑不急，我慢慢看”，不是“我再也不怕了”。
- 奖励、掌声或贴纸的处理：小星贴纸是路径提示，不是奖励、奖章或勇敢证明。
- 禁用表达：“别怕”“要勇敢”“你都这么大了”“别人都不怕”“不拿到杯子就不行”“真乖”。

## 4. 故事设定卡

- 背景：傍晚家中客厅和一段短走廊，走廊尽头有低杯架和小米的小蓝杯。
- 儿童视角：变暗、看不清影子、听见沙沙声、牵住一根手指、看到小灯照出的日常物件。
- 故事弧线：生活入口 -> 想拿小蓝杯 -> 走廊变暗脚停住 -> 说出害怕 -> 成人给选择 -> 牵手走近 -> 看清影子 -> 认出声音 -> 留下小星线索 -> 拿到杯子并说出自己的办法。
- 重复结构：“看一看”逐次变化：看黑黑的走廊、看小外套影子、看窗边绿叶、看小星线索。
- 页间推进：每页新增一个动作、选择或发现，不连续重复同一站位。
- 温暖结尾：小米拿到杯子，妈妈仍在旁边；孩子拥有语言和方法，而不是被评价。
- 故事禁改项：不出现怪物化黑暗；不把怕黑写成缺点；不把贴纸写成奖励；不让妈妈强拉小米前进。
