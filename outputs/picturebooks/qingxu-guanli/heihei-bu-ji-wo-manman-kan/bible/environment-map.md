# 《黑黑不急，我慢慢看》环境与空间连续性地图

## 时间与天气

- 时间：傍晚到夜晚刚开始，室内光线从暖黄客厅过渡到蓝紫走廊。
- 天气：普通安静夜晚，不出现雷雨、闪电或惊吓性停电。

## 核心场景

客厅与相连的短走廊。客厅在画面左侧，短走廊从中右侧向后延伸，走廊尽头右侧是低杯架，小蓝杯放在杯架上。窗边有绿植，墙边有挂钩和小外套，暖色台灯在客厅提供安全光源。

## 空间骨架

- 起点：客厅地毯边，小米站在客厅与走廊交界处。
- 目标点：走廊尽头偏右的低杯架。
- 行动路线：客厅地毯 -> 走廊口 -> 挂钩与小外套旁 -> 窗边绿植旁 -> 杯架。
- 路径轴线：从画面左前方通向右后方，整本保持“客厅左、走廊右、杯架远端”的关系。
- 固定地标：客厅地毯、暖色台灯、走廊口门框、墙面挂钩、小外套、窗边绿植、低杯架、小蓝杯。
- 角色进入/离开方向：小米从左侧客厅向右后方走廊移动；妈妈从小米身旁或后方蹲低陪伴。
- 镜头主侧与越轴线：以客厅看向走廊为主侧；反打时必须保留门框、杯架或客厅暖灯作为锚点。
- 主光源方向：客厅台灯从左侧发暖光；小月亮灯从低处向走廊局部照亮；窗外蓝色傍晚光只作柔和背景。

## 允许变化项

- 镜头景别可从远中景切到近景、手部特写或孩子视角。
- 走廊亮度可随小月亮灯出现而局部变暖。
- 小米和妈妈的距离可变化，但妈妈始终在可回应距离内。

## 禁改项

- 不得把走廊画成漫长、阴森、未知空间。
- 不得出现怪物、尖牙、爪影、第三个人影或惊吓性形状。
- 不得让小米攀爬高柜、摸电线或使用成人工具。
- 杯架必须低矮安全；小蓝杯必须可由小米站立拿到。
