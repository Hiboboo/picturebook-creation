# 《黑黑不急，我慢慢看》色板与风格圣经

## 画面风格

- 媒介：温柔水彩和彩铅细线。
- 线条：柔软、清楚、不过度描黑。
- 纹理：轻纸感颗粒，避免塑料皮肤、过量高光和强烈数码感。
- 人物比例：幼儿圆润比例，成人温和自然；表情有层次，不能全员同款微笑。
- 细节密度：适中偏简洁，只保留叙事道具和空间锚点。

## 色板

| 类型 | 色彩 | 用途 |
|---|---|---|
| 主色 | 明亮暖黄 | 小米上衣、星形贴纸；必须清爽干净，不被全局黄褐滤镜污染 |
| 主色 | 浅蓝 | 小米背带裤、小蓝杯、傍晚空气感 |
| 主色 | 蓝紫夜色 | 走廊变暗但不恐怖 |
| 辅助色 | 奶油白 / 浅米白 | 墙面、妈妈上衣、柔和反光；不得出现脏黄墙面 |
| 辅助色 | 鼠尾草绿 | 妈妈围裙、窗边绿植 |
| 辅助色 | 暖木色 | 地板、杯架、家具 |
| 强调色 | 柔和红 | 小米红色软底鞋，少量角色识别 |
| 强调色 | 柔和奶白光 | 小月亮灯；只提供局部照明，不像强烈黄色灯泡 |

## 清爽傍晚光线控制

- 整体亮度：比当前偏暗样张提亮约 `15%-25%`，保持柔和明亮，适合 `2-5` 岁儿童观看。
- 全局色调：清爽真实的傍晚室内光线；禁止暗黄滤镜、复古棕黄色调、低曝光、旧照片色、脏黄墙面。
- 墙面：奶油白、浅米白或浅暖灰，不能整面黄褐；减少大面积黄墙空白，用窗外蓝光、浅色墙、局部家具层次打破空洞。
- 暖光范围：暖光只来自台灯和小夜灯，且只影响局部，例如台灯周围、人物脸侧、地板一小块；不得形成全画面黄褐覆盖。
- 冷光范围：窗外与走廊保持柔和蓝紫冷光，但不能黑糊；必须能看见地板、杯架、墙角和短走廊边界。
- 小月亮灯：柔和奶白光，亮度低、边缘软，不画成强烈黄色灯泡。
- 人物肤色：自然、清透、有生活感，不偏橙、不偏灰。
- 衣服颜色：小米上衣是明亮暖黄，背带裤是清浅蓝；妈妈奶油白上衣和鼠尾草绿围裙要清晰，不被黄色覆盖。
- 禁止提示词：`no sepia filter, no muddy yellow overlay, no dark brown cast, no underexposed room, no old-photo tone, no heavy amber color wash`。

## 情绪用光

- 第 1-2 页：客厅浅米白墙面、窗外蓝光和局部台灯暖光并存，安全基调明确但不暗黄。
- 第 3-4 页：走廊偏蓝紫，亮度只轻微降低，仍能看见地板、杯架和墙角。
- 第 5-8 页：小月亮灯加入，以柔和奶白光帮助看清影子和叶子。
- 第 9-10 页：小星贴纸、小蓝杯和奶白小灯形成孩子自己的安全线索，画面仍保持清爽傍晚感。

## 版式锁定

- 画幅：`3:4` 竖版。
- 锁定像素尺寸：`1536x2048`。
- 安全边距：文字、脸部、手部、关键道具距离边缘至少 `6%`。
- 正文：每页 1-2 行为主，最多不超过 3 行。
- 封面：书名第一视觉层级；署名固定 `图/文：小葫芦`。
- 文字区：使用墙面、窗帘旁、客厅暖光上方等自然低细节区域；不得用固定卡片或不透明大背板。
- 图像阶段：全部无字插画，禁止模型生成中文、英文、数字、标签、墙面可读文字或伪文字。

## 禁用倾向

- 阴森低照度、纯黑大面积压迫。
- 恐怖蓝紫、霓虹紫、强对比惊悚光。
- 随机彩虹色、糖果色、过度高饱和。
- 过量星星、花朵、气泡、墙画或无关装饰。
- 暗黄滤镜、脏黄墙面、全局琥珀覆盖、复古棕黄色调、旧照片感、欠曝光。
